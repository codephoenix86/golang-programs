# golang-programs

A growing collection of Go programs written to build strong fundamentals and language fluency.

---

## Purpose

This repository is a personal Go learning journal. Each program is a focused, self-contained exercise targeting specific concepts from the Go language — written to reinforce not just *what* to write, but *why*.

Programs are numbered in the order they were written.

---

## How to Run Any Program

Make sure you have [Go installed](https://go.dev/dl/). Then navigate into any program folder and run:

```bash
go run main.go
```
